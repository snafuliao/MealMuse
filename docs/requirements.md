## 项目目标

做一款帮助用户管理「每天吃什么」的软件。主要基于 Agent 实现每日菜谱推荐与问答，结合个人风格、口味和日常饮食信息，提供合理的个性化推荐。

## 目标用户

初期供用户本人及身边的人使用。

## 首版核心范围（已确认）

1. 优先做好每日个性化菜谱推荐。
2. 推荐的菜需要说明食材准备和烹饪方式。
3. 提供围绕饮食与菜谱的 Agent 问答。
4. 一键购买：首版只做调研，不交付可用功能。调研目标是实现把所需食材加入盒马等生鲜超市的购物车。

## 后续功能

- 一键购买落地（依据首版调研结论）。
- 日常饮食管理。
- 冰箱库存管理。

## 平台与技术意向

- 手机端：首版支持 iOS。
- Web 管理端：首版负责模型配置与菜谱管理。
- 菜谱数据库：PostgreSQL + pgvector（2026-10-12 确认）。
- 用户最初考虑过 Tauri，技术栈确认时改选 SwiftUI 原生 iOS + TypeScript 服务端与 Web 管理端；完整结论见 `docs/design-docs/core-beliefs.md`。
