# 产品规格：每日推荐与饮食问答（iOS）

- **状态**：草稿，待用户评审
- **日期**：2026-10-12
- **来源**：`docs/requirements.md` 首版范围第 1–3 条，以及 2026-10-12 的产品决定（见文末）

## 1. 用户与账号

- 你在管理端生成邀请码，发给身边的人；对方在 App 首次打开时输入邀请码和昵称，即创建账号。
- 服务端发放设备令牌，App 存进 Keychain，之后免登录。换手机时要用新的邀请码，或由管理员重新发码。
- 每个人的口味档案、推荐、反馈、对话互相独立。

## 2. 口味档案（首次使用时引导填写，之后可随时改）

| 项 | 内容 | 用途 |
|---|---|---|
| 用餐安排 | 平时做哪几餐（早 / 午 / 晚，可多选）、每餐几个人 | 决定推荐哪几餐、用量按几人份换算 |
| 过敏原 | 多选（花生、坚果、海鲜、蛋、奶、麸质等）+ 自填 | **硬约束**：绝不推荐含这些成分的菜 |
| 不吃的食材 | 自由添加（如香菜、内脏） | 硬约束 |
| 饮食方式 | 无限制 / 素食 / 蛋奶素 / 不吃猪肉 等 | 硬约束 |
| 口味偏好 | 辣度 0–3；喜欢的菜系（川、粤、家常…）；偏甜、偏酸、清淡等标签 | 软偏好，影响排序 |
| 厨具 | 有没有烤箱、空气炸锅、蒸锅、高压锅等 | 硬约束：不推荐需要没有的厨具的菜 |
| 厨艺与时间 | 厨艺 1–3 档；工作日、周末每餐最多花多少分钟 | 硬约束（时间）+ 软偏好（难度） |
| 饮食目标 | 自由文本，如「控糖」「多吃蔬菜」「增肌」 | 软偏好；不做医疗判断 |

## 3. 每日推荐

### 3.1 结构

- 按用户勾选的餐次给出当天推荐。每餐一套搭配，默认规则如下（以后可在档案里调整）：
  - 早餐：1 道主食，可再加 1 道小菜或饮品；
  - 午餐 / 晚餐：1–2 人时「一荤一素」，3 人以上时「一荤一素一汤」，必要时加主食。
- 每道菜显示：菜名、一句推荐理由（指回口味或近期饮食，例如「这周还没吃过鱼」）、预计耗时、难度。
- 打开 App 时生成当天推荐，当天内结果固定，不会每次打开都变。

### 3.2 菜谱详情

- **食材准备**：按「主料 / 辅料 / 调料」分组，用量已按这一餐的人数换算；标出需要提前处理的步骤（如腌制、泡发）。
- **做法**：分步骤，每步带预计时长和小贴士。
- AI 新生成、还没审核的菜，显示「AI 新菜」标记，并提醒用户留意用量。

### 3.3 调整与反馈

- **换一道**：任何一道菜都可以替换，可附一句要求（如「换个不辣的」「想吃鱼」）。替换后同一餐的搭配仍要合理。
- **整餐重排**：重新生成这一餐。
- **反馈**：每道菜可以标「做了」「喜欢 / 不喜欢」并写一句备注。这些记录用于：
  - 避免短期重复（默认 7 天内不重复同一道菜，可设置）；
  - 调整之后的口味排序；
  - 后续「日常饮食管理」功能的数据基础。

## 4. 饮食问答

- 在 App 里与 Agent 对话，回答流式输出。
- 范围：菜谱与做法（「红烧肉怎么不腻」）、食材替换（「没有料酒用什么代替」）、搭配与采购、基于自己档案和近期饮食的建议（「这周吃得太油了吗」）。
- Agent 可以执行动作，执行后在对话里明确告诉用户结果：
  - 搜索菜谱、打开菜谱详情；
  - 替换今天推荐里的某道菜；
  - 记录反馈；
  - 修改口味档案——**必须先在界面上让用户确认**，不能直接改。
- 涉及疾病、用药、孕期等健康问题时，只给常识性建议，并提示咨询医生或营养师。

## 5. 不在首版范围

- 一键加入生鲜平台购物车（调研结论：首版不可行，见 `docs/design-docs/one-click-purchase-research.md`）。
- 「采购清单 + 跳转」：调研推荐的最小形态，是否纳入首版**待用户确认**（见 `docs/exec-plans/active/v1-daily-recommendation.md` 的里程碑 M5）。
- 日常饮食管理、冰箱库存管理（后续功能）。
- Android、多语言。

## 6. 验收标准

1. 新用户凭邀请码注册、填完档案后，3 秒内看到当天第一餐开始流式出现，30 秒内看完整天的推荐。
2. 1000 次随机档案的离线评测中，推荐结果违反过敏原、忌口、饮食方式、厨具、时间这五类硬约束的次数为 0。
3. 已标「不喜欢」的菜 30 天内不再推荐；7 天内不重复推荐同一道菜（菜谱库候选足够时）。
4. 「换一道」10 秒内返回结果，且新菜满足附加要求。
5. 问答在模型不可用时给出明确提示，不卡死；每日推荐在模型不可用时退回到基于规则的推荐。
